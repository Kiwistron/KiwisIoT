# KiwisIoT

KiwisIoT is a professional MQTT-based IoT SDK for ESP8266 and ESP32 boards.

It provides simple APIs for WiFi connection, MQTT publish/subscribe, and real-time cloud communication for the KiwisIoT platform.

---

## 🚀 Features

- Auto WiFi connect & reconnect
- Auto MQTT reconnect
- JSON publish support
- Receive callback handler
- Unique device ID generation
- Compatible with ESP8266 & ESP32
- Lightweight and easy integration

---

## 📦 Installation

### Arduino Library Manager (After Approval)

Download ZIP from GitHub and install via:
